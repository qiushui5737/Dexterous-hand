# Dexterous Hand

基于 RAPID Hand 思路改进的灵巧手实机上位机，面向 Windows、FE-URT-2、TTL Hub 和飞特 HL-3606-C001 舵机。

程序和完整使用说明位于 [上位机](上位机/README.md)。首次使用请按该说明安装 Python 依赖和飞特官方 SDK，再启动 `上位机/启动上位机.bat`。

当前包含关节与舵机绑定、零位采集、手动姿态发送、新舵机 ID / 波特率配置、差动映射、实机监视、反馈曲线和数据导出。仅向已绑定的舵机发送目标。

随仓库提供的 JSON 是未标定模板，需按实际机械结构设置 ID、零位、传动比例和限位。实际设备标定、运行记录、虚拟环境及第三方 SDK 不包含在仓库中。

外部视觉联动提供逐行 JSON 的 TCP 接收接口；视觉识别代码和完整的 20 自由度视觉角度适配不包含在本次上位机版本中。具体协议见上位机说明。
