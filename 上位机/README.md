# 直驱灵巧手实机控制台

用于 Windows、FE-URT-2、TTL Hub 和飞特 HL-3606-C001。双击「启动上位机.bat」启动，优先使用项目的 `.venv`。界面仅用于实机，保留舵机监视、目标 / 反馈曲线、运行日志和差动映射四个页签。

启动、加载配置、拖动滑块、选择预设、零位预览均只更新目标，不打开串口或驱动舵机。反馈位置、电流、电压和温度只来自实际设备返回的数据。手动发送、采集绑定零位、新舵机配置或启动视觉联动时才访问串口。

## 新舵机与绑定

1. 首先保存原有绑定配置。新舵机配置 ID 时，Hub 总线上只连接待配置的这一台，断开其他舵机，避免重复 ID。
2. 在左侧选择 FE-URT-2 对应串口与波特率，打开「新舵机配置 · ID / 波特率…」。先读取当前参数，未知 ID 时可在当前波特率下扫描。常见出厂值为 ID 1、1000000。
3. 填写新 ID 和波特率，确认单台连接后写入。副 ID 同步为主 ID；可同时初始化位置模式 0、分辨率 1、应答级别 1。程序使用新地址回读并回锁，过程中不发送转动指令。重新上电后再读取核对，然后接回其他已配置的舵机。
4. 点击右侧「关节绑定…」。单台调试时先清空模板绑定，再选择关节、舵机 ID、比例 / 方向、软限位、限流与限速，添加并应用。未绑定关节仅显示目标，不产生舵机命令。
5. 把机构放在定义的关节零位，保持静止并关闭扭矩，点击「采集绑定零位…」。只读取已绑定的 ID；完成后用当前位置作为舵机零位，保持软限位相对零位的范围。
6. 调节目标角度，再点击固定显示的绿色「发送当前姿态」。确认后仅控制已绑定舵机，到位后卸载；停止、超时或异常也进入卸载流程。「保存绑定配置…」保存 ID、零位、限位及比例，之后可用「打开标定配置…」加载。

新增绑定默认相对舵机零位 ±5°、250 mA、5 RPM。范围和比例需要按机械结构设置；同一 ID 的多条关节贡献相加，同一 ID 共用零位、限位与速度。修改绑定会使标定失效，需重新采集绑定零位。

独立的只读检查按钮已移除。采集零位、发送前的模式 / 供电 / 限位校验、运行反馈读取和卸载确认仍自动执行；新舵机配置窗口保留读取与扫描，用于配置未绑定的设备。

## 目标与反馈

目标编码 = 零位编码 + round(各关节角度乘对应比例之和 × 4096 / 360)。绑定窗口的负比例表示反向，固定齿轮传动比也通过此比例设置。MCP / CMC 两轴差动可为同一对舵机配置不同权重；「差动映射」页显示各轴贡献和组合目标。

任何已绑定舵机目标超出软限位时，整次发送被拒绝。首次发送先保持当前位置、确认扭矩开启，再发送最终目标；单台要求应答和目标回读，多台使用批量写入。运行中检查目标保持、扭矩状态、供电及位置反馈，不自动增大限流或在故障后重新使能。

「未到位超时」表示目标通过范围检查，但未在根据距离、限速和加减速计算的时间内稳定到位。错误信息与日志会列出实际位移、剩余偏差、扭矩和电压等。状态字「正常」仅表示舵机没有报告硬件故障，是否到位另由位置反馈判断。

「目标 / 反馈曲线」和「导出本次数据 CSV…」只使用本轮收到的实机数据。开始新操作或加载配置会清空本轮采样，需保留的数据请先导出。「停止」或 Esc 结束当前操作；串口中断导致卸载无法确认时，按提示切断舵机电源。

## 外部视觉联动

控制台仅接收外部视觉 TCP 数据，不内置角度数据源。加载已采集零位的绑定配置，点击「启动视觉联动」，然后由视觉端连接 `127.0.0.1:8765`，发送每行一帧 JSON：

```json
{"joints_deg":{"index_mcp_flex":0,"index_mcp_abd":0,"index_pip_flex":0,"index_dip_flex":0}}
```

上例对应食指配置；其他配置须提供该配置的完整关节名称集合，包括未绑定关节，目标仅映射到已绑定 ID。角度单位为度，按机器人关节零位定义；首帧与舵机当前位置的差须在约 5° 内。原视觉仓库的 12 通道角度仍需适配名称、基准和机械传动关系后才能发送。

启动或取消联动均保留串口独占与退出卸载流程。命令行实机服务示例：

```powershell
.\.venv\Scripts\python.exe hand_control.py serve --port COM4 --config joint_bindings.json --enable-motion
```

命令行服务必须提供真实串口、已标定的非空绑定配置和 `--enable-motion`，不提供本地数据源或无串口运行方式。

## 依赖与资料

在 Windows 上安装带 Tkinter 的 Python 和 Git，进入本 README 所在的 `上位机` 目录后运行：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
git clone https://github.com/ftservo/FTServo_Python.git FTServo_Python
git -C FTServo_Python checkout 9e6e342f6011dc727ba7144fc835bca5357b3ca9
.\.venv\Scripts\python.exe hand_gui.py
```

飞特 SDK 单独从官方仓库下载，不随本仓库重复打包。上面的提交号对应本机使用的 SDK 版本；安装后应存在 `FTServo_Python/scservo_sdk/hls.py`。主程序仅使用 Python 标准库、Tkinter、pyserial 和该 SDK。以后也可双击「启动上位机.bat」启动。

`index.json`、`pinch.json`、`full_hand.json` 分别是食指、拇食指和整手的未标定模板，不能直接用于实机动作。应按实际 ID、零位、传动比例和限位建立绑定并完成标定。自己的标定文件建议保存在 `.local/`；运行数据、实际标定、虚拟环境和 SDK 不纳入版本控制。

回归检查使用测试替身，不打开真实串口或驱动舵机。在上位机目录运行：

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -q
```
